How to read the result:
- Instagram: "Sorry, this page isn't available" = probably free. Instagram also hides
  recently deactivated handles that you still can't register, so the real test is the
  sign-up / change-username field, which says "username isn't available" if taken.
- TikTok: "Couldn't find this account" = probably free; confirm in the edit-profile
  username field.
- Facebook Pages: the page URL 404ing is not enough. Facebook usernames are global
  across profiles and Pages; confirm when setting the Page username.

Rule from the brief: if all three aren't free, move to the next name. Don't accept an
underscore or `_official` suffix.
